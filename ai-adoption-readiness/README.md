# AI Adoption Readiness Framework

A simple self-assessment tool that scores an organization's readiness for AI across six areas:
Strategy, Data, Technology, Talent, Governance and Culture.

## Run
Open `index.html` in any browser. No installation or server needed.

## Files
- `index.html` - page structure
- `style.css` - styling (colors are variables at the top; dark mode included)
- `script.js` - questions (`DIMS`), score bands (`LEVELS`), scoring, radar chart

## Customize
- Edit the `DIMS` array in `script.js` to change questions and recommendations.
- Edit the `LEVELS` array to change score bands and maturity labels.
